# Structural Studio V3

Nuevo sistema experimental. No altera versiones anteriores del pórtico.

- Vídeo 84 s: estructura calculada → restricciones → giro/curvatura → momento → cortante → recapitulación.
- ManimGX verdadero, voz masculina **Alex natural**, 18 eventos temporizados; no se modifica el pitch.
- Biblioteca de diagramas genérica `structural_viz` + controles de convención + PyNite externo.
- Motion Canvas (comparación vectorial; no es motor principal); Remotion (end card opcional).

Consulta [guía detallada](docs/README.md).
