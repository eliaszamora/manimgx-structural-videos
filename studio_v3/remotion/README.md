# Remotion — posproducción opcional

Tarjeta final de 6 s en 1080p/30 fps. **No** sustituye los diagramas ni las verificaciones. Se puede concatenar al video validado con FFmpeg después de revisión humana.

Usar solo bajo [licencia gratuita individual / pequeños equipos elegibles](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md); no implica necesariamente costo para uso personal. Configuración aislada para evitar instalar Node/Chromium en cada render ManimGX.

```bash
npm install
npm run render
```
